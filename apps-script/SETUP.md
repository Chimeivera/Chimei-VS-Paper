# 全院共用同步：Google 試算表＋Apps Script（準備版）

## 現階段
- 此資料服務放在 **shared-sync-staging-20261117 測試分支**，**未部署**，正式網站仍維持瀏覽器本機匯入。
- 此版本備妥 Google Sheets 共用讀取、歷史資料防覆寫、完整備份與 Google 授權發布函式。
- 尚未啟用「任何知道網址者都可寫入」：公開寫入會使醫院數據遭惡意或誤操作修改，且 GitHub Pages 無法保護寫入密鑰。

## 設定方式
1. 使用醫院允許的 Google 帳號建立**專用試算表**，只開放必要人員存取，不要設成「知道連結的任何人可編輯」。
2. 新增 `Published`、`Staging` 工作表；第一列需依照 `Code.gs` 中的 `HEADERS` 20 個欄位及順序。
3. 開啟「擴充功能 → Apps Script」，貼上 `Code.gs`。
4. 「專案設定 → 指令碼屬性」新增 `SPREADSHEET_ID`，值為試算表網址 `/d/...` 中的 ID。
5. 初始資料先放入 `Staging`，在 Apps Script 編輯器執行 `publishFromStaging` 授權、驗證及建立第一版 Published。
6. 部署 → 新增部署 → 網頁應用程式。先依院內資料保護政策決定存取範圍，確認 Google 帳號權限設定；取得 `/exec` 網址後再串接網站，不能先猜網址。
7. 新版 Excel 在上傳前需保留 20 個必要欄位。若任何既有流水號、申請序號對應的紀錄被移除或改寫，程式會拒絕發布。

## 還需要的最後步驟
- 由院方確認可公開的欄位；目前原始資料包含人事號及內部簽核欄位。
- 妳部署 Apps Script 並提供 `/exec` 網址後，才能將網站改為讀取共用 Published，並進行端對端測試。
- 若要做到**公開網頁任何人直接上傳並同步寫入**，必須另設受保護的寫入管道（例如限制在組織帳號），不能把私密憑證硬寫在 HTML。這不一定需要獨立的「管理員畫面」，但寫入權限不可省略。
